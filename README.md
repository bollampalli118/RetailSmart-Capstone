# 🛍️ RetailSmart Capstone Project (End-to-End Data Analytics)

## 🚀 Project Overview

This project delivers a complete **retail analytics solution**, transforming raw transactional data into actionable business insights.

It covers:

* Data Cleaning & Transformation
* Customer Segmentation (RFM)
* Churn Prediction (Machine Learning)
* Sales Forecasting
* Business Intelligence Dashboard (Power BI)

---

## 🧠 Business Problem

RetailSmart faces:

* ⚠️ 99% one-time customers
* 📉 Declining repeat purchases
* ❌ High churn rate (~20%)

👉 Goal: Improve retention & increase customer lifetime value.

---

## 🏗️ Project Architecture

```
Raw Data → Cleaning → Feature Engineering → ML Model → Insights → Power BI
```
